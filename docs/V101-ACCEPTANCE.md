# V101 — Hugo’s supper table: a bounded story prototype

Purpose: test whether a resident, a meaningful choice and a persistent consequence make an island visit worth continuing. The 5–10-minute estimate is a design target, not measured playtime. No user enjoyment or retention has been validated.

- One illustrated story at /world/hugo-supper: approach Hugo’s closing stall; examine carrots, chalkboard or empty chair; listen; decide; personalize the evening; linger and return. Clues, progress and choices persist across devices. Visitors can read the invitation; passport login saves play.
- Three equally valid endings: sell, cook for yourself, or share supper with Hugo. Each has distinct dialogue, table imagery and an ending detail. The map entry and personal market scene remember the choice. No new levels, shops, daily-repeat requirement or completion bonus.
- No farming prerequisite. Default is Hugo’s story-only ingredients: they never enter inventory and their sale does not credit the player. Explicitly choosing two own carrots consumes exactly two available units on confirmation. Displayed carrots stay reserved. Own-crop sale uses a token-bound fixed quote (currently 8 bear coins, the existing 4-per-unit price). Cooking/sharing credits no coins. Costs and consequences appear before confirmation.
- Additive migration0025 creates private story state and expiring actions. A single guarded update plus triggers atomically advances the story, debits crops and writes existing wallet/ledger receipts. Owner checks, strict fields, same-origin form checks, revision guards and unique action tokens prevent forged, competing, repeated or stale settlements. Ledger uses new labels; existing collection/economy behavior is preserved. No edits to applied migrations or player backfill.
- Optional ending feedback asks whether the player wants to meet Hugo again (yes/unsure/no). It is account-scoped, not public, and has no reward or effect on characters. This prototype does not add passive analytics or send messages.
- Scene has original SVG art, existing canonical Hugo/player avatars, a gentle optional stir interaction, native keyboard/touch controls, responsive one-column choices, large text and reduced-motion support. Native forms function without JS. Hash returns put observations/feedback below the fixed header. Scene SVG was inspected offline; that is not browser acceptance.

Validation passed: source and compiled story integration, source collection/character life, bear world, farm orders, garden, adventure, resort navigation, pocket inline, garden inline, task return, player experience, i18n, build and ESM artifact. Story tests cover all three endings, no-farming path, explicit source default, once-only price/crop settlement, display reservation, altered replays, stale revisions, expiry, cross-account/origin/extra-field guards, changed stock and injected-ledger atomic rollback/retry, map/market consequences, optional reward-free feedback and unchanged legacy passports.

Verification limit: required Sites cua_repl.js tool is unavailable; browser/physical-device visuals and real-player playtime/enjoyment remain unverified. No production player rows were read or mutated for tests. Recommend observing 3–5 target players before expanding the story system.

Publication: pending native deployment and production schema verification. Rollback to platform118 preserves the new tables and all previous saves; do not drop tables or rewrite migration history.
