## Site selection and implementation

Fixed northern green parcel, approximately x=414–530/y=164–215 in the existing 940×608 map. It sits between the north woodland and upper promenade, away from the existing café, sports, cottage and reception footprints. Approach is stop 12 at (470,240), connected through (510,230) to the sports path. All existing stop indices remain stable. The map uses fixed graph navigation rather than free walking: no graph edge enters the fence. No artificial physics/collision engine was added.

Native WebGL/Canvas geometry supplies ground, contact shadow, wood fencing, excavator base/cab, bamboo/wood stacks, stone pile, toolbox and sign. A light SVG arm animation and helmeted builder overlay remain visible on the native 3D scene; the complete SVG construction fallback also works without WebGL. Reduced-motion and the existing map pause control disable the arm movement. This is projected geometry, not a new rigged excavator simulation.

Sixth map entrance leads to `/world/nomad`, with a bilingual conceptual preview of four future areas, honest construction status and no announced opening date. Return retains stop 12. Semantic i18n keys use the existing V84 runtime; changing language does not reload the map. There is no focus timer or seating in this batch.
