# V87.2 — Registration-to-map welcome tour

The user wants onboarding on the map immediately after registration. The V87 journal entry was not an adequate substitute.

## Behavior

After creating a new passport, the existing one-time recovery-code confirmation leads to /world by default. Explicit invitation/return destinations remain intact. New accounts receive a private tour_auto flag; their first map request activates Ari's five-stop guide, rendered before the map layout. /world and the existing /islands map alias share the same behavior.

The guide introduces harbor, Banyan Square, home, Cedar Woods and Shell Beach. The matching map entrance is outlined (forest/beach use the nature-area entrance), with next/previous, skip and optional scene visits. It is an in-map introduction, not forced travel or a movement tutorial. All five overview steps stay on the map. Native forms work without JavaScript; no overlay blocks the island.

Current step, skip and completion persist per account. Replay resets only the guide step, preserving completion and all gameplay state. Existing accounts see a collapsed map replay entry; there is no forced old-account backfill. The prior device-local welcome markup is kept hidden for its resident-chat integration, with its visual guide suppressed for these signed-in map pages, so two guides are not shown. Guests retain their existing signup help.

## Data and validation

Migration 0018 adds constant-default tour_step and tour_auto columns to existing adventure preferences. New-account creation alone sets tour_auto; editing an existing passport does not reset onboarding. Same-origin account-authenticated POST actions validate current step and use conditional updates. Tutorial completion never creates exploration events or quest rewards.

Traditional Chinese and English use the existing catalog. Entry links retain the V87.1 light contrast; controls are at least 44px with keyboard focus. New highlighting is static and does not depend on animation. World-script/catalog URLs are cache-bumped.
