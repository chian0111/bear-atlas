Production logs confirmed repeated POST /world/[object%20HTMLInputElement] responses with HTTP404. Garden forms have a hidden input named action; HTMLFormElement named-property lookup shadows form.action with that input. V96.3 passed it to fetch as a URL. Fix: read the action HTML attribute via getAttribute, resolve it against the current URL, and require the same origin and /world/garden path before fetching.
